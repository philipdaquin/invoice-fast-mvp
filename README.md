# Invoice Fast ⚡

A simple invoice generator for freelancers and small businesses. Create professional invoices in seconds.

## Features

- **Simple form** — Enter client details, line items, and notes
- **Live preview** — See exactly what your invoice will look like
- **Print to PDF** — Use browser print to save as PDF
- **Auto-calculations** — Subtotal, tax (10%), and total calculated automatically

## Quick Start

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS

## Usage

1. Fill in your details
2. Add client information
3. Create line items (description, quantity, rate)
4. Click "Preview Invoice"
5. Use browser's "Save as PDF" to download
